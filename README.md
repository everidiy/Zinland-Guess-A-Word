# 🏝️ Волшебный Остров Зинленд - Guess Word Game

## 🎮 **Как играть**

### Основная механика:
1. **Выбери класс персонажа** - каждый класс имеет свою тематику слов
2. **Угадывай слова по буквам** - у тебя есть 5 попыток на каждое слово
3. **Сражайся с монстрами** - каждый монстр загадывает слово
4. **Победи всех монстров** - освободи все слова класса
5. **Сразись с финальным боссом** - последнее испытание с 3 попытками

### Управление:
- **Вводи русские буквы** по одной
- **Следи за попытками** (осталось/всего)
- **Запоминай использованные буквы**
- **Нажимай любую клавишу** для продолжения истории

## 🎯 **Правила игры**

### ✅ Что можно:
- Использовать любые русские буквы
- Видеть использованные буквы
- Следить за оставшимися попытками
- Перезапускать игру при поражении

### ❌ Что нельзя:
- Вводить больше одной буквы за раз
- Использовать не русские символы
- Повторять уже использованные буквы
- Пропускать ход (нужно вводить букву)

### ⚠️ Важно:
- **5 попыток** на обычных монстров
- **3 попытки** на финального босса
- После поражения — возврат к выбору класса
- После победы над боссом — возврат в меню
